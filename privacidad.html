Política de privacidad

BEIK STUDIO · Última actualización: 7 de noviembre de 2026

BEIK STUDIO es una aplicación de escritorio para Windows que graba la pantalla, organiza las grabaciones en una biblioteca y las publica en YouTube, Facebook, Instagram y TikTok. Es una herramienta privada, creada y usada por Jordan Marmolejo Sanchez. Esta política explica qué datos toca la aplicación y qué hace con ellos.

Quién es el responsable

Jordan Marmolejo Sanchez. Contacto: Jordanmarmolejosanchez@gmail.com.

Qué datos maneja la aplicación

  • Tus grabaciones y capturas. Los vídeos, las miniaturas, las copias con texto y los informes se guardan en tu propio equipo, en la carpeta Vídeos\BEIK STUDIO y en la carpeta de datos de la aplicación.
  • La biblioteca. Una base de datos local con el nombre, la fecha, la duración y el estado de cada clip, y el historial de publicaciones.
  • Las credenciales de tus cuentas (YouTube, Facebook, Instagram y TikTok), cuando las conectes. Se guardan en tu equipo con los mecanismos de protección de Windows. Se conectan una sola vez y puedes desconectarlas cuando quieras.
  • Los datos mínimos de cada cuenta que la plataforma devuelve al conectarla, como el nombre del canal, de la Página o de la cuenta, para mostrar a qué cuenta vas a publicar.

Qué NO hace la aplicación

  • No envía tus grabaciones, tus credenciales ni tus datos a ningún servidor del autor ni a terceros, salvo la publicación que tú pidas.
  • No usa analíticas, rastreadores, publicidad ni perfiles.
  • No vende ni comparte datos.
  • No publica nada sin tu autorización expresa en cada publicación.

Cuándo se envía algo fuera de tu equipo

Solo cuando pulsas Publicar. En ese momento la aplicación envía el vídeo, el título, la descripción y los hashtags que tú escribiste a la plataforma o plataformas que elegiste, con la cuenta que conectaste.

Servicios de terceros

Cada plataforma trata los datos según sus propias condiciones y su propia política de privacidad:

  • YouTube. Se usa la YouTube Data API para subir vídeos a tu canal. Al conectar tu cuenta aceptas los Términos del servicio de YouTube y la Política de privacidad de Google. El uso y la transferencia que BEIK STUDIO hace de la información recibida de las API de Google se ajustan a la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.
  • Facebook e Instagram (Meta). Se usa la API de Meta para publicar Reels en tu Página de Facebook y en tu cuenta profesional de Instagram.
  • TikTok. Se usa la Content Posting API de TikTok para enviar vídeos a tu cuenta.

Cómo retirar el acceso y borrar tus datos

  • Puedes desconectar una cuenta desde la aplicación o revocar el acceso desde la configuración de seguridad de cada plataforma (Google, Facebook, Instagram o TikTok).
  • Para borrar los datos locales, elimina la carpeta Vídeos\BEIK STUDIO y la carpeta de datos de la aplicación, o desinstala la aplicación.
  • Si quieres que se borre cualquier dato relacionado contigo que el autor pudiera tener, escribe a Jordanmarmolejosanchez@gmail.com.

Menores

La aplicación no está dirigida a menores de 13 años y no recoge datos de menores de forma intencionada.

Cambios en esta política

Si la aplicación añade funciones que cambien el tratamiento de datos, por ejemplo servicios de inteligencia artificial que analicen tus clips, esta política se actualizará antes y se pedirá tu consentimiento. La fecha de arriba indica la última revisión.

Contacto
